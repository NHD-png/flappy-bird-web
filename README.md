# flappy-bird-web
Link: https://poetic-profiterole-c1bd16.netlify.app

A small Flappy Bird-inspired web game built as a personal side project.

About: This project was created during a few free days as a way to practice web development and game logic.

Features:
- Bird movement and gravity
- Pipe generation
- Collision detection
- Score tracking
- Game over and restart
- Simple browser-based gameplay

Technologies:
HTML
CSS
JavaScript

Purpose: A small personal project focused on practicing JavaScript, game logic, and interactive web development.
Note: This is a simple personal project, so the visual design is intentionally minimal.
